# Studio OS — Industrial Designer Dashboard

## Vision
A single dashboard that mirrors the actual industrial design process — from brief to handoff. Replace Notion + Google Drive + email with one focused tool.

## Target User
Industrial designer (solo / small studio) who manages multiple client projects simultaneously.

## MVP Features (Build Order)

### Epic 1: Project Hub
1. **Feature 1.1** — Project Board (Kanban by phase: Brief → Concept → Development → Handoff)
2. **Feature 1.2** — Project Detail Page (briefing, deliverables checklist, file uploads)
3. **Feature 1.3** — Materials & Suppliers Tracker
4. **Feature 1.4** — Client Feedback Log

## Tech Stack
- Next.js 15 (App Router)
- Convex (database + file storage)
- Clerk (auth)
- Tailwind + shadcn/ui
- Vercel (deployment)

## Deferred (V2)
- Portfolio showcase
- Time tracking
- Client login
- 3D file preview
- Team collaboration
