## THE 7 PILLARS APPLIED TO EVERY PROMPT

| Pillar | Application |
|--------|-------------|
| 1. Direction Over Description | Imperative verbs: "position," "light," "frame" — NOT "beautiful scene with..." |
| 2. Technical Specificity | Exact camera + lens + aperture + color temp + lighting direction |
| 3. Strategic Imperfection | Film grain, dust particles, skin pores, stray hairs, caught-between-moments |
| 4. Mood Before Objects | Emotion/feeling opens every prompt BEFORE product placement |
| 5. Systems Over Single Images | Reference image method — generate hero, then unlimited variations |
| 6. Frame-Based Thinking | Foreground + Midground + Background layers in every prompt |
| 7. Tool Fluency | Nano Banana Pro for product consistency with reference uploads |

### FORBIDDEN WORDS
- NO "beautiful," "nice," "professional photo," "stunning"
- NO "standing," "sitting," "holding" — use MID-ACTION verbs instead
- NO poetic language ("poetry," "journey," "narrative")
- NO production equipment ("reflector," "scrim," "softbox")
- NO "photoshoot," "photo session"
- NO "golden hour" or "magic hour" — triggers stock-photo AI aesthetic

### ANTI-AI PHRASES
```
"NOT veneer-perfect teeth"
"NOT airbrushed skin"
"NOT peak expression intensity"
```

## CRITICAL RULES FOR ALL PROMPTS

### PRODUCT PLACEMENT — NON-NEGOTIABLE
The BACE hub sits DIRECTLY on the ground — cobblestone, asphalt, pavement, sidewalk. **NO concrete foundation. NO pedestal. NO raised platform. NO base slab.** Bottom edge touches ground directly.

### PRODUCT ACCURACY — NON-NEGOTIABLE
Compact rectangular container module, approx. 2.3m tall, 3-4m wide. GRID OF LOCKER COMPARTMENTS on the front face. Small window section on one side. Touchscreen interface panel. "bace" branding. WHITE/CREAM color. Reproduce reference EXACTLY.

### PEOPLE — NON-NEGOTIABLE
- 1-2 people per scene ONLY. Intimate, personal, NOT crowded.
- Age: 20-40. More women than men across the full set.
- Ethnicity: DIVERSE across the full set — Black, Middle Eastern, South Asian, East Asian, Southern European, Northern European. Rotate through prompts.
- Fashion: COS, Arket, Zara, Uniqlo. Earth tones + one color accent. Modern urban. NO formal wear.
- Mood: HAPPY. Genuine contentment, small pleasures, private satisfaction, easy smiles, relaxed joy. NOT forced. NOT stock-grin. The happiness of a good moment in a normal day.
- Skin: Pores visible. NOT airbrushed.
- Hair: Stray hairs, texture, NOT salon-perfect.

### LIGHTING — NON-NEGOTIABLE
**NO golden hour. NO magic hour. NO amber wash.**
Real daylight: bright overcast, direct sun, open shade, cloudy-bright, post-rain, mixed.
Each prompt uses a DIFFERENT lighting condition.

### CAMERAS — NON-NEGOTIABLE
Premium bodies with distinctive rendering: Leica M11, Hasselblad X2D 100C, Leica Q3, Fuji GFX 100S, Leica SL2-S. Each prompt uses a DIFFERENT camera.

### EDITORIAL TONE
Cereal Magazine. The Gentlewoman. i-D. Apartamento. Monocle. COLORS.
NOT Kinfolk (too cozy). NOT lifestyle blogs. NOT stock photography.

### HOW IT WORKS — THE 4-STEP CUSTOMER FLOW

```
1. APPROACH  → Walk/cycle/drive to your nearest BACE hub
2. SCAN      → Scan the QR code with your phone (NO app needed, NO registration)
3. SELECT    → Choose your service: Pick up / Shop / Drop off / Rent
4. DONE      → Locker opens, take your item or deposit it. Walk away. Under 60 seconds.
```

**Key UX detail for prompts:** People interact with the hub via their PHONE (QR scan) and the hub's TOUCHSCREEN. No keys, no cards, no codes. Phone + screen = the entire interface.

## WAS LÄUFT AUF EINEM BACE HUB — Hub Capabilities & Features

Source: bacehub.de/hubs — "Ein Ort, an dem Pakete, Produkte, Services & Menschen zusammenkommen."

### WHAT IS A BACE HUB?

"Ein bace Hub ist eine modulare Infrastruktur für die letzte Meile."

- For **users:** A place to handle daily errands — pickups, shopping, returns, rentals
- For **cities, real estate, businesses, retailers:** A scalable infrastructure building block
- Controlled via **QR code + web app** — no app download, no registration needed
- Self-developed **hardware + software platform** (bace Plattform)

---

Both hub types run the SAME services. The only difference is WHERE and HOW they are deployed.

**"Der bace Hub für deinen Standort, dein Viertel oder dein Gebäude"**

For high-volume locations with extended infrastructure needs.
